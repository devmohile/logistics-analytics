# Quick Start

## 1. Setup
```bash
python3 scripts/etl_pipeline.py
```

## 2. Query in VSCode
- Install "SQLite" extension
- Open data/logistics.db
- Open queries/analysis_queries.sql
- Run queries

## 3. Results
See warehouse performance, order metrics, and delivery analysis.
