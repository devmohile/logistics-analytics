# Logistics Analytics Platform

A comprehensive SQL-based analytics project for warehouse/logistics operations.

## Quick Start

```bash
# 1. Install pandas
pip install pandas

# 2. Run ETL pipeline
python3 scripts/etl_pipeline.py

# 3. Query results in VSCode
# - Install SQLite extension
# - Open data/logistics.db
# - Open queries/analysis_queries.sql
# - Run queries
```

## Project Structure

- **data/raw/** - CSV source files
- **data/logistics.db** - SQLite database (generated by ETL)
- **scripts/etl_pipeline.py** - Data loader
- **queries/analysis_queries.sql** - 10 SQL analysis queries
- **analysis/** - Quality reports and insights

## Data Files

- warehouses.csv (5 rows)
- orders.csv (20 rows)
- shipments.csv (19 rows)
- deliveries.csv (11 rows)
- tickets.csv (7 rows)

## Key Metrics

- 20 orders in 10-day period
- 60% completion rate
- 100% on-time delivery
- 4.45/5.0 customer satisfaction
- 7 support tickets (5 resolved, 2 open)

## SQL Queries Included

1. Warehouse Performance
2. Order Status Distribution
3. Delivery SLA Analysis
4. Customer Satisfaction
5. Ticket Analysis
6. Order Lifecycle Tracking
7. High-Risk Orders
8. Capacity Utilization
9. Carrier Performance
10. Daily Trend Analysis
